# Desktop workstation

The Windows workstation combines source selection, synchronization settings, a multitrack waveform timeline, multicamera monitoring, an inspector, diagnostics, and project history. Waveform peaks are visualization data and do not constitute synchronization evidence.

Match Review presents competing placements with waveforms and available video. Audition windows can be adjusted and shuffled. Use A/B audio to compare the recordings, then accept, confirm, or reject a candidate. Decisions are recorded in revision history and can be undone. A confirmation and an independently validated acoustic relationship carry different provenance.

The monitor follows the timeline playhead and displays active camera feeds. Buffering, decoding limits, and source storage speed affect smooth playback. The desktop backend and frontend are in `internal/desktop/` and `desktop/`.
