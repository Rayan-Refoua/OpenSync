# Terms and evidence

| Term | Meaning |
| --- | --- |
| Recording | A source media file with its own source time. |
| Offset | A relative timing relationship between recordings. |
| Candidate | A proposed pair and offset for further investigation. |
| Hypothesis | One possible timing explanation for a pair. |
| Supported | Evidence favors a relationship, which may need additional corroboration. |
| Validated | A relationship passed its applicable independent checks. |
| Provisional | A placement retained with explicit uncertainty. |
| Chronological estimate | A placement inferred from ordering or timing metadata. |
| Unresolved | A recording has no sufficiently established placement. |
| Component | Recordings connected by timing relationships. Separate components have unknown relative timing. |
| Drift | A change in relative timing caused by differing clocks or other timing behavior. |
| Anchor | An observed timing relationship at a point in a recording. |
| Residual | The difference between a timing observation and a fitted model. |
| Manual confirmation | A saved user decision about a candidate. It records human judgment. |

A timeline track is a presentation container. It does not itself establish that its recordings are synchronized. See [Timing and chronology](./timing.md).
